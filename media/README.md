# Put your own files here

This folder is for your manual uploads.

## Super simple idea

1. Copy your image or video into this `media` folder.
2. Change the file path inside `firebase-config.js`.
3. Example:
   - `logoPath: 'media/my-logo.png'`
   - `heroImagePath: 'media/main-photo.jpg'`
   - `throwbackImagePath: 'media/day-one.jpg'`
   - `filmVideoPath: 'media/batch-film.mp4'`
   - `behindScenesVideoPath: 'media/bts-loop.mp4'`

## Important

- Keep file names simple.
- Do not use weird symbols.
- If something does not appear, double-check the file name and extension.
